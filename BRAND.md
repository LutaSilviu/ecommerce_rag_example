# Nexo Market Brand Notes

**Status:** Temporary prototype brand. The name, visual treatment, and copy in this file are replaceable product decisions, not permanent identity requirements.

## Working name

**Nexo Market**

Use this name in the prototype until a final store name is selected. Avoid embedding it independently across components, templates, API responses, or page-specific scripts. Keep the store name in one shared brand/configuration source and have the UI read it from there, so a rename requires one intentional change. The document title, header wordmark, footer, and any welcome or confirmation copy should use that same source.

## Wordmark direction

Use a simple text wordmark: **Nexo** with **Market** as a smaller or lighter companion. A compact geometric sans-serif, clear letter spacing, and a small teal or deep-blue accent are suitable. It should remain readable at mobile header size and work without a separate logo image. Do not imitate eMAG's logo, colors, or distinctive visual identity.

This is guidance, not a locked design system. The implementation should keep colors and brand name in shared tokens/configuration rather than repeat literal values throughout the UI.

## Voice and tone

- Romanian-first, clear and friendly.
- Practical and concise; make price, delivery, availability, and next steps easy to understand.
- Reassuring around account and checkout actions without claiming that prototype orders or payments are real.
- Use standard Romanian diacritics in visible text.

## Tagline candidate

**„Tot ce-ți trebuie, într-un singur loc.”**

This is a draft tagline for the prototype and can be changed or omitted without affecting product behavior.

## Usage notes

- Product-facing interface copy is Romanian, as specified in `SPEC.md`.
- Display prices in RON with Romanian locale formatting.
- Keep mock order/payment wording explicit; branding must never make a prototype order sound like a completed real transaction.
- Treat Nexo Market as a placeholder identity. Do not register domains, create external accounts, or assume trademark availability as part of this implementation task.
